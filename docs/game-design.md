# godot-voxel-block-smash 游戏设计（GDD v3）

来源：2026-10-26 用户本轮明确规则。对标《这关消一消》，仅按下述规则实现，不从名称推断额外玩法。Intel Mac mini、Godot 4、Goxel；个人学习，不发布；最终验收在安卓模拟器完成。

本版替代旧版“无关卡”和缺失 GDD 登记；旧日志保留。旧版冷却、重置不再作为本轮玩法需求；本轮新增关卡列表和各关独立状态，替代此前禁止关卡选择/进度系统及存档的限制；保存的持久化范围见D09。不新增计分、掉落物理碎块、背景音乐。连击计数不等于计分系统。保留既有工程约束：300～1200 个体素、单 MultiMeshInstance3D 绘制模型、禁止逐块 Node；模型绕自身中心旋转、UI 不触发旋转。

## 权威规则与观测验证项
| ID | 规则 | 观测验证项 |
|---|---|---|
| G01 | 上方为独立纯色体素组成的立体模型，可拖拽自由3D旋转；UI、炮台池、槽固定不随转 | 模型中心世界坐标不随旋转改变；方向日志改变；测试人员描述模型位于上区、可从不同角度观察；UI 操作时方向不变；旋转模型时UI、池、槽屏幕坐标不变 |
| G02 | 中间为发射槽；从下方炮台池选择炮台安放，点击槽内炮台独立逐个发射；最多5槽，满槽禁止放入；未发射炮台可取回九宫格 | 每次成功安放后所有权唯一；点击空槽不发射；槽计数不超过 5；报告槽位在模型下方；单次只发射所点炮台；取回后槽清空且池中唯一出现 |
| G03 | 下方为 3×3 炮台卡片池，每个炮台有颜色和弹珠数 | 布局行列各 3；卡片颜色 ID、显示数与状态一致；九宫格位置及遮挡由测试人员描述 |
| G04 | 弹珠只能消除发射炮台同色体素；异色只反弹不消除 | 同色命中产生一次删除事件；异色存活数不变、碰撞后速度方向符合反射；判断用离散 color_id，不用颜色浮点比较 |
| G05 | 一次发射消耗一颗；数字减一；归零炮台消失 | 成功发射数与弹量消耗相等；1→0 时炮台移除且本次弹珠仍存在；拒绝发射不扣数 |
| G06 | 仅九宫格内同颜色炮台可合成，数量相加且设有限合成上限 | 合成前 a+b 等于合成后数量；两个原炮台仅保留一个结果；不同颜色拒绝且状态不变；不得从槽内合成；交互、上限数值及超限处理待D02 |
| G07 | 弹珠持续反弹至飞出有效边界直接消失或停止运动；生命周期结束立即清零连击；连击仅视觉反馈，不增加消除伤害；同色消除触发短时受限粒子 | 每个成功删除只增加一次连击并请求一次效果；异色反弹不增加连击；出界/停止事件提交时连击为0；相同轨迹不同连击的消除数量不变；停止及多球语义待 D03 |
| G08 | 速度×2使下一次发射弹珠飞行速度翻倍 | 同一基础速度下发射速度模长为 2 倍；影响范围与消耗状态有事件记录；连续点击语义待 D04 |
| G09 | 加槽位解锁额外发射槽，永久作用于本局，上限5 | 解锁后可用槽数增加且不超过 5；满槽再使用不越界；初始数量与单次增量待 D01 |
| G10 | 任意指仅作用于下一次发射的弹珠，临时取消颜色限制，可消除任意色 | 有效期内异色体素可删除；失效后恢复同色规则；后续发射不继承；下一发及道具消费语义见D04 |
| G11 | 随机排刷新整个九宫格炮台池，换一批全新炮台 | 一次刷新替换全部池格内容；记录随机种子和前后卡片；槽中炮台不属于刷新目标；生成分布待 D05 |
| G12 | 所有体素清空即通关；顶部剩余数实时显示 | 删除提交后权威存活数和 HUD 数相同，最迟下个 UI 更新帧可见；1→0 只触发一次通关；通关后的操作规则待 D06 |
| G13 | 四种道具均为消耗型，每个有使用次数，用完消失 | 使用记录含前后次数；次数不负；归零后UI中消失；失败操作消费策略待D04 |
| G14 | 尚有未清除方块，同时九宫格没有任何炮台可以用来发射、无法继续消除，则失败 | 记录余块、池/槽可用炮台、活跃球和道具状态；完全无继续消除手段时仅一次失败事件；边界冲突按D08澄清，禁止仅凭池空提前判失败 |
| G15 | 从关卡列表进入；每关绑定独立模型，独立保存本局炮台、道具、进度 | 列表选择ID与模型ID一致；A→B→A恢复A状态，B不被A的操作改变；跨进程保存范围待D09 |

## 未决项与阶段门禁（禁止执行 Agent 自定数值）
| ID | 需要明确的内容 | 阻塞范围 |
|---|---|---|
| D01 | 初始开放槽数、单次解锁数量、满槽反馈、池空格是否补充；取回目标选择/池满行为；“未发射”是否仅指从未发射过的炮台 | 阶段4槽与池最终行为 |
| D02 | 九宫格内合成手势、结果格、明确正整数合成上限和超限处理（拒绝/其他须用户明确），禁止截断数字造成弹量丢失 | 阶段4合成 |
| D03 | 发射起点/方向、半径/基础速度、有效边界几何与反弹面的区分、同色击碎后轨迹、阻尼/停止阈值、是否允许多球及连击归属、飞行时旋转规则；出界直接消失已确定 | 阶段3碰撞相关接口定稿及阶段4运动/连击 |
| D04 | 各关道具初始次数、触发方式、激活或成功发射时扣次、连续激活如何处理、失败操作和满槽时是否消费、速度与任意指组合；两者都绑定下一次发射，不得自行叠加成4倍 | 阶段4道具 |
| D05 | 正式模型主题/数量/许可范围、精确调色板、炮台初始数字/颜色分布、随机排如何保证全新（新ID或数值也不同）及生成分布 | 阶段2正式素材选择和阶段4生成/终局 |
| D06 | 屏幕方向、UI尺寸安全区、自由3D旋转操作/灵敏度/多指策略、胜负反馈与后续操作、音效需求 | 阶段3输入定稿、阶段5表现 |
| D07 | 模拟器设备/API/ABI/分辨率、帧率/帧时间/内存阈值、最大活跃弹珠、粒子总量/单次量/寿命上限、性能测试时长 | 阶段3容量配置、阶段5～7性能验收 |
| D08 | 池空但槽有弹量、活跃球尚能消除、随机排尚有次数时是否延后失败；有炮台但颜色不匹配是否算“不可用”；胜负同帧优先级 | 阶段4失败判定定稿 |
| D09 | 关卡列表数量/顺序、保存是仅会话还是跨应用重启、离开时飞行球/连击/待发道具处理、终局后再次进入行为、保存时机 | 阶段3存储后端与阶段4关卡切换 |

上述缺项不阻塞阶段1。只有受影响任务被阻塞；Codex 在相应阶段开始前整理需求问题，由用户决定后更新本文件。测试夹具可用于算法验证，必须标明测试值，不得作为正式玩法默认值。

## 可复现测试用例
通用证据：构建标识、用例编号、固定种子/夹具、输入序列、帧号、预期/实际、事件日志路径、测试者画面现象描述。未决前提未确认的用例记 BLOCKED；未执行记 NOT_RUN，不得推定通过。

| 用例 | 前置与操作 | 可观测预期 |
|---|---|---|
| T01 | 加载合法 300 块与 1200 块模型，另测重复坐标/非法色/非法数量 | 合法存活数正确、单模型 MultiMesh；非法数据拒绝并报告字段；无逐块节点 |
| T02 | 拖动模型；从每类 UI 开始拖动并移出；取消/失焦 | 模型拖动中心不变；UI 起始手势不改变方向；取消后没有残留指针 |
| T03 | 选择卡片、放入可用槽、重复操作及满槽操作 | 成功安放唯一所有权；非法操作不改变弹量/所有权；具体反馈按 D01 |
| T04 | 点击数量2炮台两次，再点空槽 | 两个成功发射事件，数量2→1→0、炮台移除；第三次不生成球 |
| T05 | 同色数量2与3合成；再尝试异色合成 | 同色结果5且源对象不重复存在；异色不合成；位置按 D02 |
| T06 | 固定轨迹分别命中同色和异色块 | 同色仅删除目标一次；异色不删除且反射法线/前后速度有记录 |
| T07 | 连续击碎三个块，再让弹珠满足停止条件 | 连击1→2→3，出界或停止立即0；连击不改变伤害；多球按D03；重复命中已删除块不计数 |
| T08 | 相同发射条件分别不使用/为下一发使用速度×2 | 初始速度模长比2，弹量仍只减1；消费范围按 D04 |
| T09 | 解锁槽直到上限，达到5后再次尝试 | 不出现第6槽，不覆盖既有炮台；道具消费按 D04 |
| T10 | 任意指绑定的下一发命中异色，再用后续普通发射命中异色 | 有效时删除、失效后只反弹；事件含有效范围标识 |
| T11 | 固定种子刷新九宫格 | 九格全部重新生成，槽炮台保持；记录种子可复现；新旧炮台ID不复用；颜色/数值是否必须不同待D05 |
| T12 | 清除最后两个体素，同时/重复提交最后一次碰撞 | 剩余数2→1→0，不为负；只出现一次通关事件；HUD 同步 |
| T13 | 1200块、批准的最大球数和粒子峰值，运行批准时长 | 报告 FPS、p95/p99帧时间、内存峰值、球/粒子峰值、节点数、碰撞耗时；与 D07 阈值逐项比较 |
| T14 | 安卓安装、启动、触屏，执行其余全部用例 | 无崩溃、解析错误或失效触控；环境和日志齐全；音效/布局/粒子附文字现象及计数 |
| T15 | 未发射炮台从槽取回池；池满和已发射炮台分别测试 | 合法取回保持ID/颜色/弹量、槽释放；其他分支按D01，拒绝时无丢失/复制 |
| T16 | 池内同色合成到上限、超上限；尝试槽内合成 | 等于上限合法；超限按D02且不能静默截断；槽内合成拒绝 |
| T17 | 用尽每种道具；再操作；连续激活下一发道具 | 次数不负、归零消失、不能重复生效；加槽结果在本局保留；下一发效果不泄漏后续球 |
| T18 | 余块>0，池/槽无炮台、无活跃球/恢复手段 | 只判失败一次；重复输入不重复终局；失败UI有文字观测 |
| T19 | 分别构造池空但槽有炮台/活跃球/随机排可用，以及最后块消除同帧池空 | 按D08批准真值表判断；未确认标BLOCKED；禁止用池空直接替代“无法继续消除” |
| T20 | A关操作后进入B关，再回A关 | 各自模型/存活集合/炮台/槽解锁/道具/待发效果/终局状态无串用；A恢复与离开快照一致（飞行球按D09） |
| T21 | 关卡切换时注入旧球事件；按批准范围重启/恢复 | 旧会话事件被拒绝；恢复后实例数=存活数、槽归属唯一；跨进程分支未确认记BLOCKED |
